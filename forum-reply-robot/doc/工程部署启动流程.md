# forum-reply-robot 工程完整部署与启动流程

## 一、项目概览

```
forum-reply-robot
├── 论坛监控回复机器人（ForumBot）
├── LightRAG 知识库管理（update_lightrag）
├── Redfish Schema 预审（SchemaValidation）
└── Flask 健康检查接口
```

### 核心依赖服务

```
┌─────────────────────────────────────────────────────────────────┐
│                     外部依赖服务                                  │
├─────────────────────────────────────────────────────────────────┤
│  1. LightRAG 服务      → 向量检索知识库 (配置: retrieval.base_url) │
│  2. 论坛 API (Discourse) → 帖子数据源 (配置: forum.base_url)       │
│  3. LLM API (SiliconFlow) → AI 模型调用 (配置: api.base_url)     │
│  4. GitCode API        → 文档仓库 (配置: gitcode.*)              │
│  5. PostgreSQL 数据库   → 数据持久化 (配置: database.*)           │
│  6. 外部搜索 API        → 相关主题搜索 (配置: search.base_url)     │
└─────────────────────────────────────────────────────────────────┘
```
